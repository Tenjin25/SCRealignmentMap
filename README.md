# South Carolina Political Realignment Map

An interactive visualization of South Carolina's electoral evolution from 2006-2024, featuring comprehensive county-level results for presidential, gubernatorial, U.S. Senate, and statewide constitutional office elections.

## 🗺️ Overview

This project provides an in-depth look at South Carolina's political landscape through interactive maps that display county-level voting patterns, margins, and competitiveness across nearly two decades of elections. The map uses a sophisticated 15-category competitiveness scale to visualize electoral dynamics from landslide victories to razor-thin margins.

**Live Demo**: [View the interactive map](https://tenjin25.github.io/SCRealignmentMap/)

## 🔴 Why South Carolina Remains Red

### The Palmetto Paradox: Red Island in a Purple Sea

While neighboring North Carolina and Georgia have emerged as presidential battlegrounds in recent cycles, South Carolina has remained consistently Republican since 1980. This divergence from regional trends is driven by several key demographic and political factors:

### Demographic Composition

**The Black-White Binary**: South Carolina has a unique demographic profile that differs significantly from its neighbors:
- **Biracial electorate**: SC's population is approximately 63% White and 27% Black, with relatively small Hispanic (6%) and Asian (2%) populations
- **Limited "New South" growth**: Unlike Atlanta, Charlotte, or the Research Triangle, South Carolina lacks a large metropolitan area attracting diverse, college-educated transplants from across the country
- **Smaller urban cores**: Charleston (~800K metro), Columbia (~800K metro), and Greenville (~900K metro) are much smaller than Atlanta (6M+) or Charlotte (2.8M+)

**Compared to Neighbors**:
- **Georgia**: Large Hispanic/Asian growth in metro Atlanta, significant Northern migration, diversifying suburbs
- **North Carolina**: Research Triangle and Charlotte draw highly-educated transplants, growing Hispanic population, younger demographics
- **Virginia**: Northern Virginia suburbs transformed by federal workforce, international migration, tech industry growth

### Educational Polarization

South Carolina's educational attainment lags behind its neighbors, reinforcing partisan patterns:
- **College degree rate**: ~28% of adults vs. 32% in NC, 33% in GA, 40% in VA
- **White non-college voters**: Comprise a larger share of the electorate and vote overwhelmingly Republican (70-75%)
- **Brain drain**: Many college-educated young adults leave for larger metros in neighboring states
- **Rural concentration**: 34% of SC residents live in rural areas vs. 24% in NC, 25% in GA

### Geographic Distribution of Democratic Votes

**Democratic strength concentrated in few areas**:
- **Columbia** (Richland County): State capital, University of SC, plurality-Black
- **Charleston** (Charleston, Berkeley, Dorchester): Growing coastal metros, tourism economy, some suburban swing
- **"Black Belt" counties**: Rural majority-Black counties in central SC (Orangeburg, Sumter, Allendale, etc.)

**Republican dominance widespread**:
- **Upstate/Piedmont** (Greenville, Spartanburg, Anderson): Evangelical conservative strongholds, manufacturing base
- **Midlands suburbs**: Lexington County is one of the most Republican suburban counties in the country (Trump +30 in 2020)
- **Pee Dee region**: Conservative rural Northeastern SC
- **Coastal counties**: Except Charleston, most coastal areas lean Republican (Horry/Myrtle Beach tourism voters)

### County-Level Deep Dive: Key Bellwethers and Polarization

#### **Greenville County** - The Upstate Giant
*Population: ~525,000 | 2020 Result: Trump 59.1% - Biden 39.5% (R+19.6) | 2024 Result: Trump 61.3% - Harris 38.7% (R+22.6)*

South Carolina's most populous county exemplifies the state's conservative foundation:
- **Bob Jones University influence**: Evangelical culture deeply embedded
- **BMW plant**: Manufacturing economy, white working-class base
- **Downtown revitalization**: Small but growing urban core around Main Street
- **Suburbs dominate**: Simpsonville, Mauldin, Greer are overwhelmingly Republican
- **Trend**: Slight Democratic movement in city of Greenville proper (Biden improved ~2 points over Clinton), but massive Republican margins in suburbs prevent countywide shift
- **Why it matters**: Contains 11% of state population; must stay deep red for Republicans to hold SC

#### **York County** - Charlotte's Conservative Spillover
*Population: ~280,000 | 2020 Result: Trump 58.2% - Biden 40.7% (R+17.5) | 2024 Result: Trump 59.7% - Harris 40.3% (R+19.4)*

Border county benefiting from Charlotte metro growth, yet remaining solidly red:
- **Charlotte exurbs**: Rock Hill, Fort Mill, Tega Cay see explosive growth from NC transplants
- **But different from NC suburbs**: Unlike Mecklenburg County (D+33), York County transplants tend to be conservative-leaning families seeking lower taxes and housing costs
- **New construction**: Fastest-growing county in SC (20% growth 2010-2020)
- **Economic profile**: White-collar commuters to Charlotte, some manufacturing
- **Trend**: Despite massive growth, Trump's 2020 margin actually *increased* from Romney 2012 (R+13.8)
- **Paradox**: Population boom hasn't brought political change like Georgia suburbs because migrants self-select for conservative policies

#### **Lexington County** - America's Reddest Suburb?
*Population: ~295,000 | 2020 Result: Trump 63.4% - Biden 35.3% (R+28.1) | 2024 Result: Trump 66.9% - Harris 33.0% (R+34.0)*

Columbia's western suburbs represent peak Republican performance:
- **Suburban structure**: Middle-class subdivisions (Irmo, Chapin, Lexington town)
- **White flight history**: Grew as white families left Columbia in 1970s-90s
- **Evangelical stronghold**: High church attendance, social conservatism
- **Education paradox**: Above-average incomes and education, yet massively Republican (defying national trends)
- **Trend**: Remarkably stable—Trump 2020 margin (R+28) almost identical to Romney 2012 (R+27)
- **Comparison**: While suburban Atlanta counties shifted 20+ points Democratic, Lexington hasn't budged
- **Why**: Homogeneous population (82% white), few transplants, culturally conservative professionals

#### **Charleston County** - The Blue Anchor
*Population: ~410,000 | 2020 Result: Biden 55.0% - Trump 43.4% (D+11.6) | 2024 Result: Harris 52.9% - Trump 47.1% (D+5.8)*

SC's most Democratic large county and best hope for future competitiveness:
- **Historic city**: Tourism, hospitality, College of Charleston, liberal urban core
- **Black plurality**: 31% Black population, historic African American communities
- **Military presence**: Joint Base Charleston brings diverse population
- **Northern transplants**: Retirees and young professionals from Northeast
- **Trend**: Strong Democratic movement—Obama won by 6 points (2008), Biden by 12 (2020)
- **Suburban dynamics**: North Charleston and West Ashley are diverse and Democratic, unlike most SC suburbs
- **Why it's different**: Only SC metro with "New South" characteristics (diversity, tourism, cultural amenities)
- **Limitation**: Only contains 9% of state population—not enough to offset Upstate

#### **Richland County** - The Capital Paradox
*Population: ~415,000 | 2020 Result: Biden 61.1% - Trump 37.2% (D+23.9) | 2024 Result: Harris 67.6% - Trump 32.4% (D+35.2)*

SC's bluest large county, but geographically isolated:
- **University of South Carolina**: 35,000+ students, liberal academic community
- **State government**: Capital city workers tend Democratic
- **Fort Jackson**: Massive Army training base
- **Black majority**: 47% Black, including large middle-class African American community
- **Trend**: Increasingly blue—Obama won by 19 points (2008), Biden by 24 (2020)
- **Geography problem**: Completely surrounded by deep-red counties (Lexington R+28, Kershaw R+36, Fairfield R+4 but rural)
- **Cannot spread**: Democratic votes concentrated in Columbia city limits, minimal suburban diffusion

#### **Spartanburg County** - The Manufacturing Heartland
*Population: ~320,000 | 2020 Result: Trump 61.5% - Biden 37.2% (R+24.3) | 2024 Result: Trump 67.0% - Harris 33.0% (R+34.0)*

BMW's anchor county represents white working-class realignment:
- **BMW effect**: German auto plant employs thousands, conservative workforce
- **Textile legacy**: Former mill towns with traditional Southern culture
- **Rural-urban divide**: City of Spartanburg itself competitive, but county as a whole overwhelmingly red
- **Wofford College**: Small liberal arts school creates pocket of Democratic votes
- **Trend**: Dramatic Republican shift—Obama lost by 10 points (2008), Biden lost by 24 (2020)
- **Explanation**: White non-college voters moved sharply right during Obama-Trump era
- **Why**: Economic anxiety, cultural conservatism, evangelical influence combine for massive GOP margins

#### **Horry County** - The Tourist Trap
*Population: ~350,000 | 2020 Result: Trump 60.5% - Biden 38.4% (R+22.1) | 2024 Result: Trump 69.5% - Harris 30.5% (R+38.9)*

Myrtle Beach's home county defies coastal trends:
- **Tourism economy**: Service workers, retirees, seasonal residents
- **Coastal Carolina University**: Growing school (10,000+ students) but limited political impact
- **Retiree magnet**: Northern retirees from rust belt—but conservative-leaning
- **Different from NC coast**: Unlike Wilmington (swing), Myrtle Beach attracts working-class tourists and conservative seniors
- **Trend**: Slight Republican increase—Romney won by 19 (2012), Trump by 22 (2020)
- **Why no shift**: Lacks Charleston's diversity, military liberalism, or cultural amenities

#### **Pickens County** - The Clemson Exception
*Population: ~130,000 | 2020 Result: Trump 69.2% - Biden 29.6% (R+39.6) | 2024 Result: Trump 76.7% - Harris 23.3% (R+53.4)*

Home to Clemson University, yet among SC's reddest counties:
- **Clemson University**: 27,000 students, engineering and agricultural focus
- **But**: Campus in small town, students often vote in home counties
- **Rural surroundings**: Agricultural Upstate, deeply conservative
- **Evangelical culture**: Bob Jones-style religious conservatism dominant
- **Stunning margin**: Trump won by 40 points despite major university presence
- **Contrast**: Most college counties (Chapel Hill, Athens GA, Charlottesville) are Democratic strongholds
- **Explanation**: Commuter students, conservative STEM focus, rural culture overwhelms campus liberalism

#### **Beaufort County** - The Military Wild Card
*Population: ~190,000 | 2020 Result: Trump 51.6% - Biden 46.9% (R+4.7) | 2024 Result: Trump 57.3% - Harris 42.7% (R+14.7)*

Marine Corps base creates SC's closest large county:
- **Parris Island & MCAS Beaufort**: Marine Corps training and air station
- **Hilton Head**: Upscale resort island, wealthy retirees (but not liberal like Martha's Vineyard)
- **Port Royal/Beaufort**: Historic town with Black and military communities
- **Diverse electorate**: White retirees (R), Black residents (D), military families (mixed)
- **Closest to flipping**: Biden came within 5 points, best performance in competitive county
- **Trend**: Shifting Democratic—Romney won by 11 (2012), Trump by only 5 (2020)
- **Why it matters**: Proof that SC *can* have competitive counties with right demographics (military diversity)

#### **Sumter County** - The Rural Blue Dot
*Population: ~105,000 | 2020 Result: Biden 52.7% - Trump 46.3% (D+6.4) | 2024 Result: Harris 52.5% - Trump 47.5% (D+5.0)*

Shaw Air Force Base creates anomalous rural Democratic county:
- **Shaw AFB**: Major fighter wing, diverse military population
- **Black plurality**: 44% Black, historic African American community
- **Small city**: City of Sumter (40,000) anchors county
- **Tobacco legacy**: Traditional rural economy with Black-white divide
- **Trend**: Competitive in presidential races, reliably Democratic in lower-turnout elections
- **Shows**: Military + Black population can overcome rural conservatism—but model not replicable elsewhere in SC

### The Missing Swing Counties

Unlike battleground states with multiple swing counties that decide elections (Bucks County PA, Maricopa County AZ, Waukesha County WI), **South Carolina has no true bellwether counties**:

- **Aiken County** (R+21): Augusta GA suburbs, but much more conservative than Georgia side
- **Anderson County** (R+33): Ancestrally Democratic textile mills, now deep red
- **Dorchester County** (R+9): Charleston suburbs trending Democratic, but too slowly

**The structural problem**: To flip SC statewide, Democrats would need to:
1. **Win Charleston by 20+** (currently D+12) ✗ Difficult
2. **Win Richland by 30+** (currently D+24) ✓ Achievable
3. **Hold Beaufort competitive** (currently R+5) ✓ Possible
4. **Cut Greenville margin to single digits** (currently R+20) ✗ Nearly impossible
5. **Cut Lexington margin in half** (currently R+28) ✗ No trend in that direction
6. **Win York County** (currently R+18) ✗ Growing but getting redder

**Conclusion**: Without massive demographic change in Greenville, Spartanburg, or Lexington, SC cannot become competitive.

### Why Neighbors Flipped But SC Didn't

**Georgia's Transformation**:
- Metro Atlanta now contains 60% of state population
- Gwinnett County flipped from R+18 (2012) to D+18 (2020) due to Asian/Hispanic growth
- Black population more urban and politically engaged
- Stacey Abrams' organizing infrastructure

**North Carolina's Competitiveness**:
- Charlotte and Raleigh-Durham metros contain 50%+ of voters
- Banking/tech industries attract college-educated professionals
- Universities (UNC, Duke, NC State) anchor liberal enclaves
- Suburbanization creating swing counties (Wake, Mecklenburg went Biden)

**Virginia's Blue Shift**:
- Northern Virginia suburbs (Fairfax, Loudoun, Prince William) transformed by federal workforce
- Hampton Roads military communities diversified
- Richmond suburbs shifted Democratic

**South Carolina's Resistance**:
- No single dominant metro to drive statewide change
- Population growth slower and less diverse than neighbors
- White non-college voters remain majority of electorate
- Black voters concentrated in safe Democratic counties, limiting statewide impact
- Conservative evangelical culture deeply rooted
- No equivalent to Atlanta suburbs, Research Triangle, or NoVA to flip moderate/swing

### Electoral Math

**2020 Presidential Results**:
- **South Carolina**: Trump 55.1% - Biden 43.4% (R+11.7)
- **Georgia**: Biden 49.5% - Trump 49.2% (D+0.3) ✓ Flipped
- **North Carolina**: Trump 49.9% - Biden 48.6% (R+1.3) - Close battleground
- **Virginia**: Biden 54.1% - Trump 44.0% (D+10.1) - Solid blue

**Key Insight**: South Carolina would need massive demographic shifts—either explosive metro growth like Atlanta, or significantly higher Black turnout coupled with suburban realignment—to become competitive. Current trends suggest it will remain 8-12 points more Republican than the nation through 2030.

### Future Outlook

**Factors that could narrow margins**:
- Charleston metro continued growth and diversification
- Columbia metro expansion and university influence
- Generational replacement among white voters
- Increased Latino population in Upstate and Lowcountry

**Why it's still unlikely to flip by 2028**:
- Slower population growth than GA/NC (0.9% annually vs. 1.5%+)
- Lexington County and Upstate suburbs remain deeply red
- Limited in-migration of Democratic-leaning voters
- Rurality and evangelical culture deeply entrenched
- No massive metro area to drive change

- Adjutant General (2006, 2014 only)

### Advanced Competitiveness Scale

Results are categorized into 15 precision tiers:
- **Republican**: Annihilation (+40%+), Dominant (+30-40%), Stronghold (+20-30%), Safe (+10-20%), Likely (+5.5-10%), Lean (+1-5.5%), Tilt (+0.5-1%)
- **Tossup**: ±0.5%
- **Democratic**: Tilt (+0.5-1%), Lean (+1-5.5%), Likely (+5.5-10%), Safe (+10-20%), Stronghold (+20-30%), Dominant (+30-40%), Annihilation (+40%+)

Each category corresponds to a distinct color on the map, allowing for nuanced visualization of competitive dynamics. This scale is particularly useful for identifying:
- **Trending counties**: Areas shifting between categories over time
- **Swing regions**: Counties oscillating between Lean/Tilt categories
- **Realignment patterns**: Suburbs moving from Safe R to Lean R (or vice versa)
- **Polarization**: Counties becoming more extreme (Safe → Stronghold)

## 📊 Data Sources

All election data is sourced from official South Carolina state records:

- **2006-2022 Elections**: South Carolina State Election Commission (ENR system)
- **2024 Election**: Official precinct-level results aggregated to county level
- **Geographic Data**: U.S. Census Bureau TIGER/Line shapefiles (2020)
- **Demographic Analysis**: U.S. Census Bureau American Community Survey (ACS) 5-Year Estimates

### Data Methodology

**County-Level Aggregation**: All results are aggregated to South Carolina's 46 counties, ensuring consistent geographic units across all elections.

**Competitiveness Calculation**: 
- Two-party vote share used for margin calculations
- Third-party votes tracked separately but not included in competitive classifications
- Margins expressed as percentage point differences (e.g., 55-45 = +10.0%)

**Standardization**:
- Candidate names normalized across data sources (e.g., "Donald Trump" vs. "Donald J. Trump")
- Party designations preserved and standardized (D/R/L/I/G)
- FIPS codes verified against official Census Bureau lists

## 🛠️ Technical Architecture

### Data Pipeline

The project includes robust Python scripts for data extraction and processing:

1. **ENR Scrapers** (`extract_2010_all.py`, etc.)
   - Automated extraction from SC Election Commission ENR JSON API
   - County-level aggregation across all 46 SC counties
   - Multi-office batch processing

2. **Data Structuring** (`fix_json_structure.py`)
   - Adds competitiveness scale metadata
   - Calculates margins and competitive categories
   - Adds party labels and candidate designations
   - Normalizes office names across years

3. **Quality Assurance**
   - Automated vote total validation
   - Cross-referencing with official sources
   - FIPS code accuracy verification

### Web Application

- **Frontend**: Vanilla JavaScript with Mapbox GL JS
- **Styling**: Custom CSS with responsive design
- **Data Format**: Structured JSON with competitiveness metadata
- **Performance**: Optimized for fast loading and smooth interactions

## 🚀 Getting Started

### Viewing the Map

1. **Online**: Visit the [live demo](https://tenjin25.github.io/SCRealignmentMap/)
2. **Local**: Clone the repository and open `index.html` in your browser

```bash
git clone https://github.com/Tenjin25/SCRealignmentMap.git
cd SCRealignmentMap
# Open index.html in your browser
```

### Working with the Data

All contest data is available in the `Data/` directory as structured JSON files. Each file contains:

```json
{
  "competitiveness_scale": {
    "Republican": [...],
    "Tossup": [...],
    "Democratic": [...]
  },
  "county_fips_code": {
    "county": "Charleston",
    "contest": "President",
    "year": 2024,
    "dem_candidate": "Kamala Harris (D)",
    "rep_candidate": "Donald Trump (R)",
    "dem_votes": 123456,
    "rep_votes": 98765,
    "margin_pct": 12.34,
    "winner": "DEM",
    "competitiveness": {
      "category": "Likely Democratic",
      "party": "Democratic",
      "color": "#4575b4"
    }
  }
}
```

### Adding New Elections

1. Extract data using the ENR scraper or manual CSV processing
2. Run `fix_json_structure.py` to add competitiveness metadata
3. Add entries to `index.html` in the `elections` and `contestMetadata` objects
4. Test the new contest in the dropdown
